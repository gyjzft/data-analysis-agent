- 数据可视化
- 数据清理
- 特征生成
- 数据连接器，连接各种数据源
- 不能做什么？暂时不清楚

### 2. 交互方式
- 文字信息，表格数据输入，可接受多个表格同时输入，多个dataframe聊天交互
- 图表/文字/表格输出，支持字符串相应，提供文本分析和解释；数字响应返回计算结果；返回dataframe
结构；图标响应；错误响应

- LLM + 代码执行
